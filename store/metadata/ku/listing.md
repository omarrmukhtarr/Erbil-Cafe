# لیستی فرۆشگا — کوردی (سۆرانی)

> **سەرەتا ئەمە بپشکنە:** کوردی سۆرانی لەوانەیە لە App Store Connect و Google
> Play Console وەک زمانێکی بەردەست نەبێت. ئەگەر نەبوو، ئەم دەقە بۆ خودی ئەپەکە
> و بۆ ماڵپەڕەکە بەکاربهێنە، و لیستی فرۆشگا بە عەرەبی و ئینگلیزی دابنێ.

## ناوی ئەپ (٣٠ پیت)
```
ErbilCafe — کافێکانی هەولێر
```

## ناونیشانی لاوەکی (٣٠ پیت)
```
کافێ، مێنیو و حیجزی مێز
```

## وەسفی کورت (٨٠ پیت)
```
کافێکانی هەولێر بدۆزەرەوە: مێنیو بە نرخی ڕاستەقینە، کاتی کارکردن، نەخشە و حیجز.
```

## دەقی بانگەشە (١٧٠ پیت)
```
٢٥٣ کافێ لە هەولێر، لە چایخانەکانی قەڵاوە تا سەربانەکانی شەقامی ١٠٠ مەتری. مێنیو بە دینار.
```

## وەسفی تەواو
```
ErbilCafe ڕێنمایی تۆیە بۆ کافێکانی هەولێر — ئەوانەی لەسەر شەقامی ٤٠ و ٦٠ مەتری،
چایخانەکانی ژێر قەڵا، سەربانەکانی عەنکاوە، و ئەو شوێنە هێمنانەی بۆ کارکردن لە
دوانیوەڕۆدا.

کافێیەک بدۆزەرەوە
· ٢٥٣ کافێ لە شارەکەدا، لەسەر نەخشە یان لە لیستێکدا
· فلتەرکردن بەپێی ناوچە، نرخ و ئەوەی شوێنەکە پێشکەشی دەکات — وای فای، نێرگیلە،
  دانیشتنی دەرەوە، بەشی خێزانی، پارکینگ
· بزانە چی ئێستا کراوەیە، لەم کاتژمێرەدا

مێنیوی ڕاستەقینە، نرخی ڕاستەقینە
مێنیو بە نرخی دیناری عێراقی، بۆ ئەوەی پێش دانیشتن بزانیت کاپوچینۆ چەندە.

مێزێک حیجز بکە
داوای مێزێک لە کافێکە بکە و وەڵام وەربگرە. لەگەڵ بیرخستنەوەیەک ئێوارەی پێشوو،
بۆ ئەوەی حیجزێکی ڕۆژی یەکشەممە تا پێنجشەممە لەبیر نەچێت.

پاشەکەوتی بکە
ئەو کافێیانە هەڵبگرە کە حەزت لێیانە. بە یەک دەست شوێنێک هەڵبسەنگێنە، یان
بیروڕاکەت بنووسە.

بە زمانی خۆت
کوردی، عەرەبی و ئینگلیزی، بە پاڵپشتی تەواوی ڕاست-بۆ-چەپ.

زانیاری کافێکان لە OpenStreetMap ـەوە دێت، بەپێی مۆڵەتی Open Database، و بە
دەست ڕاست دەکرێنەوە.
```

## نووسینی ژێر وێنەکان
1. **هەموو کافێکانی هەولێر لە یەک شوێندا**
2. **وێنە، کاتی کارکردن و مێزێک کاتێک دەتەوێت**
3. **٢٥٣ کافێ لەسەر نەخشە، کراوە یان داخراو بە یەک تەماشا**
4. **فلتەر بەپێی ناوچە، نرخ و پێویستیت**
5. **مێنیو بە نرخی ڕاستەقینەی دینار**
