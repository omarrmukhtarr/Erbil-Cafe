# قائمة المتجر — العربية

## اسم التطبيق (٣٠ حرفاً)
```
ErbilCafe — مقاهي أربيل
```

## العنوان الفرعي — App Store (٣٠ حرفاً)
```
مقاهٍ وقوائم وحجز طاولات
```

## الوصف القصير — Play (٨٠ حرفاً)
```
اكتشف مقاهي أربيل: قوائم بأسعار حقيقية، أوقات العمل، خريطة، وحجز طاولة.
```

## النص الترويجي — App Store (١٧٠ حرفاً)
```
٢٥٣ مقهى في أربيل، من مقاهي القلعة إلى أسطح شارع ١٠٠ متر. قوائم بأسعار حقيقية بالدينار.
```

## الوصف الكامل
```
ErbilCafe دليلك إلى مقاهي أربيل — تلك التي على شارع ٤٠ و٦٠ متر، ومقاهي الشاي
تحت القلعة، والأسطح في عنكاوا، والأماكن الهادئة للعمل بعد الظهر.

ابحث عن مقهى
· ٢٥٣ مقهى في المدينة، على الخريطة أو في قائمة
· فلترة حسب المنطقة والسعر وما يوفره المكان — واي فاي، أركيلة، جلسات خارجية،
  قسم عائلي، موقف سيارات
· اعرف ما هو مفتوح الآن، في هذه الساعة

قوائم حقيقية بأسعار حقيقية
قوائم بالأسعار بالدينار العراقي، لتعرف سعر الكابتشينو قبل أن تجلس.

احجز طاولة
اطلب طاولة من المقهى واحصل على رد. مع تذكير في المساء السابق، حتى لا يُنسى
حجزٌ تم يوم الأحد بحلول الخميس.

احفظ وشارك
احتفظ بالمقاهي التي تحبها. قيّم مكاناً بلمسة واحدة، أو اكتب رأيك.

بلغتك
الكردية والعربية والإنجليزية، مع دعم كامل للكتابة من اليمين إلى اليسار.

معلومات المقاهي مصدرها OpenStreetMap، مستخدمة بموجب رخصة قواعد البيانات
المفتوحة، ومصححة يدوياً.
```

## تعليقات لقطات الشاشة
1. **كل مقاهي أربيل في مكان واحد**
2. **صور وأوقات عمل وطاولة حين تريدها**
3. **٢٥٣ مقهى على الخريطة، مفتوح أو مغلق بنظرة**
4. **فلترة حسب المنطقة والسعر وما تحتاجه**
5. **قوائم بأسعار حقيقية بالدينار**
